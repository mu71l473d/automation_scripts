## android-bruteactivities
Script to bruteforce different activities within the app. If the phone is rooted it will also try exposed activities gotten from the phone. 

## android_installstudio
android_installstudio installs android studio and the fastboot tools from google instead of the adb installed ones (which are bugged)

## android_logappdata
A script to use adb logcat on a specific app package

## android_pullapk
android_pullapk pulls apk's from an android device, names them, sorts them and attempts to upload them to mobsf.

## android_setproxy
android_setproxy sets the adb proxy for eth0 or wlan0 for use with a test phone

## android_unsetproxy
android_unsetproxy unsets the adb proxy for eth0 or wlan0 for use with a test phone

## create-hotspot / remove-hotspot
Will create a hotspot with name Kiwa-Hotspot by default. 

## dcode64 
dcode64 decodes a string with base64

## ezfind
uses find to find files and folders. Capital insensitive and skip errors.

## fix-apt
if you have apt problems i feel bad for you son. I've got 99 problems and apt is also one (but this script will most likely solve it)

## Fix-display
checks various settings for display errors. 

## generate-password
does what it says

## generate-softwareversions
generates a list of the software versions in apt, .git and go.

## kiwa-rangefinder
checks for ranges of default gateways. mainly useful for labscans. 

## mobsf
Attempts to start the mobile security framework from a default location.

## mobsf_scanapp
mobsf_scanapp accepts an .apk, .zip, or .ipa for scanning with mobsf and uses the built in api to scan the app.  

## install.sh
creates a symlink to ~/.local/bin so you have it in your path.

## kiwarecon
a wrapper around autorecon that uses kiwa specific settings

## set-flameshotfolder
sets the flameshot folder to current or provided directory

## start-smbserver
starts an smbserver in the current folder and sets username and password

## mobsf_scanapp
Allows a tester to upload apk, ipa or zip for scanning with mobsf

## reinstallwithdepends
reinstalls the provided app with also all of its dependencies

##zbbruter
Bruteforces common zigbee channels. 

## zip-currentdir
zips the current dir and encrypts it with a password
